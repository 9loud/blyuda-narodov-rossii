# Блюда народов России

Школьный проект учеников 9М класса — Кирилла Чурсинова и Кирилла Кольчика (школа №2, г. Мурино, 2026 год).

Интерактивный сайт-каталог кухонь шести народов России: русской, татарской, башкирской, осетинской, бурятской и якутской. На главной странице — кликабельная карта России, в каталоге — поиск по названиям и ингредиентам, фильтры по кухням и категориям. У каждого из 18 блюд — история, состав, пошаговый рецепт и фотография.

## Как открыть

Сайт не требует сборки и интернета: откройте `index.html` прямо с компьютера или с флешки. Он же работает и на GitHub Pages.

## Структура

- `index.html` — главная: карта России с шестью кухнями
- `catalog.html` — каталог блюд: поиск, фильтры, карточки, окно с рецептом
- `about.html` — о проекте: актуальность, цель, задачи, авторы, источники
- `assets/` — стили, скрипты, шрифты и фотографии
  - `assets/js/data.js` — весь контент проекта (кухни, блюда, рецепты)
  - `assets/js/credits.js` — источники фотографий (Wikimedia Commons)
- `_docs/` — доклад и презентация к защите проекта
- `_scripts/` — служебные скрипты: генератор карты, подбор и обработка фотографий, скриншоты (на сайте не используются)

## Технологии

Только HTML, CSS и JavaScript — без библиотек и сборки. Карта России построена по открытым геоданным проекта Natural Earth (коническая проекция Альберса), фотографии блюд взяты с Wikimedia Commons под свободными лицензиями, авторы и лицензии указаны в разделе «О проекте» и в карточке каждого блюда.

## Публикация на GitHub Pages

1. Создайте на github.com публичный репозиторий, например `blyuda-narodov-rossii` (без README).
2. В папке проекта выполните:

   ```
   git remote add origin https://github.com/ВАШ-ЛОГИН/blyuda-narodov-rossii.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages**: выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/blyuda-narodov-rossii/`.

Папки `_staging`, `_scripts` и `_docs` при публикации автоматически пропускаются — на сайте их не видно.
